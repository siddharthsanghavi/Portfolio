It mimics a Studio 5000 / Logix Designer environment — ladder logic (LD), structured text (ST) and function block (FBD) routines all editable side by side — backed by a live I/O simulator panel with toggleable digital inputs, analog sliders and a controller tag table that updates in real time as rungs execute. It's been my go-to way to drill PLC concepts like seal-in circuits, timers, counters and interlocks between internships.

A tool I came up with at Beckhoff to simulate and plan EtherCAT networks before touching real hardware. It's a drag-and-drop rail builder — search the full Beckhoff terminal catalog, snap couplers and I/O terminals onto a rail, and wire connections between them — with a live station summary (DI/DO/AI/AO counts and E-bus current draw), automatic validation warnings (like flagging TwinSAFE I/O with no safety master present), and an auto-generated bill of materials you can copy out or export to Excel, XML or a topology diagram. Built it to make it faster to spec and sanity-check a station layout for customer demos instead of doing it by hand.
